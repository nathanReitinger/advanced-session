A note on scraping data
  • check for robots.txt (rules for scrapers)
  • Claude may try to slow a scrape down to prevent server overload; there are workarounds (Selenium), but most involve custom scraping code that you would need to build
  • If you are heavily or routinely scraping a website, it might make sense to reach out to the website's owners and ask them about preferred procedures
  • Many companies that provide access to valuable information (e.g., Westlaw or Lexis) heavily restrict scraping with technical blocks and contractual terms concerning text and data mining. When in doubt, check terms first

Step 3 — Explicit verification
Task: Check that the dashboard correctly displays party names.
Tips

A decision about the party name may be a computable task, if the data is found online in a machine-readable format. However, if the party name is pulled from a PDF, then it might have errors.

  • This dataset is small, so we might be able to check all PDFs manually, but with larger datasets it might be better to check a random 10% and only keep the AI-assumed names if there is agreement between what you would decide and what the AI decided.

Example: a script that asks for a GPU

Save this on the cluster as gpu_check.sh, and change pXXXXX to your allocation.

gpu_check.sh
#!/bin/bash
# ============================================================
#  A tiny job that just asks: "Do I have a GPU?"
#  Everything starting with #SBATCH is an instruction to Quest.
#  Everything starting with plain # is a note to you (ignored).
# ============================================================

#SBATCH --account=pXXXXX          # your allocation (looked up from Quest)
#SBATCH --partition=gengpu        # the general-access GPU machines
#SBATCH --gres=gpu:1              # "give me 1 GPU"
#SBATCH --nodes=1                 # 1 computer
#SBATCH --ntasks=1                # running 1 thing
#SBATCH --cpus-per-task=1         # 1 CPU core alongside the GPU
#SBATCH --mem=8G                  # 8 gigabytes of memory
#SBATCH --time=00:05:00           # 5 minutes, max. Then Quest kills it.
#SBATCH --job-name=gpu_check
#SBATCH --output=gpu_check_%j.out # where the results get written (%j = job number)

echo "=========================================="
echo "Job ran on machine: $(hostname)"
echo "Started at: $(date)"
echo "=========================================="
echo ""

echo "--- Does this machine see a GPU? ---"
nvidia-smi

echo ""
echo "--- Finished at: $(date) ---"
Example: the same check, as a Python program

This is the same check, written as a short Python program. Save it on your laptop as gpu_check.py, copy it to the cluster, ask for a GPU machine, and then run python3 gpu_check.py there.

gpu_check.py
# gpu_check.py: is there a GPU here?
# Run it with: python3 gpu_check.py
import shutil
import socket
import subprocess
from datetime import datetime

print("Machine:", socket.gethostname())
print("Started:", datetime.now())

if shutil.which("nvidia-smi") is None:
    print("No GPU here (no nvidia-smi).")
else:
    gpu = subprocess.check_output(
        ["nvidia-smi",
         "--query-gpu=name,memory.total",
         "--format=csv,noheader"],
        universal_newlines=True)
    print("GPU:", gpu.strip())

print("Finished:", datetime.now())
